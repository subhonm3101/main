# Подключение панели владельца DoniШеф

Сайт остаётся статическим, а Supabase обеспечивает защищённый вход, базу данных и хранилище фотографий.

## 1. Создайте проект

Создайте проект в Supabase и откройте **SQL Editor**. Выполните весь файл [`supabase-schema.sql`](./supabase-schema.sql). Он создаёт каталог, заявки, снимки состава заказа, контакты ресторана, проверки доступа и хранилище `menu-photos`. Если проект уже настроен, выполните обновлённый файл повторно, чтобы добавить таблицу контактов или телефон для звонков; существующие номера сохранятся.

## 2. Создайте учётную запись владельца

В **Authentication → Users** добавьте владельца с email и паролем. В настройках Authentication отключите публичную регистрацию пользователей. Затем выполните в SQL Editor запрос, заменив email на адрес созданной учётной записи:

```sql
insert into public.admin_users (user_id)
select id
from auth.users
where email = 'owner@example.com'
on conflict (user_id) do nothing;
```

Только идентификаторы из `admin_users` получают доступ к заказам и редактированию меню и контактов. Не добавляйте в эту таблицу обычные клиентские учётные записи.

## 3. Подключите сайт

В **Project Settings → API** скопируйте Project URL и публичный ключ `anon` / `publishable`. Впишите их в `supabase-config.js`:

```js
window.DONISHEF_SUPABASE_CONFIG = {
  url: 'https://ВАШ-ПРОЕКТ.supabase.co',
  anonKey: 'ВАШ-ПУБЛИЧНЫЙ-КЛЮЧ'
};
```

Публичный ключ предназначен для браузера; доступ к данным контролируют SQL-политики. **Никогда не помещайте в этот файл `service_role` или secret key.**

Опубликуйте файлы сайта на HTTPS-хостинге. Затем откройте `/admin.html`, войдите под созданной учётной записью и нажмите **«Загрузить исходное меню»**. Если каталог уже загружен, кнопка **«Обновить шашлыки»** заменит только позиции категории «Мангал» на новые позиции с сайта; остальные блюда останутся без изменений. Цены и позиции можно менять в панели, добавлять блюда, удалять старые, задавать фотографии, категории и порядок. Для загрузки фотографии выберите файл в форме блюда.

## Какие данные видны в панели

- В заказах сохраняются заявки, оформленные через сайт, состав блюд, цены на момент заказа и контактные данные. Заказ сохраняется до перехода клиента в WhatsApp или MAX.
- В разделе «Контакты для звонков» владелец меняет телефон ресторана и номера WhatsApp и MAX. Телефон для звонков показывается на сайте; WhatsApp используется для открытия чата, а MAX — для отображения номера получателя скопированного сообщения. Номера хранятся в международном формате, например `+79191545232`.
- Номер WhatsApp используется сайтом для открытия чата. Для MAX сайт копирует текст заявки, а клиенту показывает сохранённый номер, который нужно найти в приложении.
- Запросы на бронирование отдельного зала пока продолжают отправляться в WhatsApp/MAX и в панели заказов не отображаются.
- Сайт не хранит данные банковских карт и не проводит оплату.

Данные клиентов являются персональными. Ограничьте список владельцев и настройте срок хранения в соответствии с правилами обработки персональных данных ресторана.
